# Shamran Motors

Responsive vehicle sales and car hire website built with TanStack Start, React,
and Tailwind CSS.

## Development

Requires Node.js 22 or newer and npm.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Deploy to Netlify

The project uses the official Netlify TanStack Start Vite plugin. Netlify reads
the build command and publish directory from `netlify.toml`; connect the
repository to Netlify and deploy.

For a local production-style test, run:

```sh
npm run build
npm run preview
```
